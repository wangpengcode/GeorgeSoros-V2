# 补跑④·最终结论（2026-10-03，curl 直连底层接口）

> 补跑②③中 akshare 的解析报错均为脚本字段假设错误，以下结论以原始 JSON 实测值为准。

## 1. 市值/股本反推（§17.1 B1）——**验证通过 ✓**

## 2. spot 板块行疑点——**排除 ✓**

## 3. 五档盘后有值性——**盘后无值（预期内）**
