## 决定性发现（源码级，inspect.getsource 实证）

**stock_cyq_em 不是东财服务端筹码接口**，它是 akshare 的本地合成实现：

1. 拉取 `push2his.eastmoney.com/api/qt/stock/kline/get` 日线（klt=101，lmt=210 根，fqt: qfq=1 / hfq=2 / ""=0 不复权）
2. 用 py_mini_racer 在**本地执行东财网页前端的 JS 筹码算法**——**150 档三角分布 + 换手衰减模型**
3. 返回前截取 `iloc[-90:, :]` → **最多 90 个交易日**

### 由此推翻的两个预设

| 预设 | 实际 |
|---|---|
| 「东财筹码是官方权威数据，可作真值基准」 | 它与我们路径 A **同族**：也是三角分布+换手衰减递推，只是档数（150 vs 200）与峰位参数不同。对拍=参数校准，不是真值校验 |
| 「历史深度足够」 | 仅 90 个交易日输出 |

### 保留的发现

- 复权口径：fqt 参数存在，默认 `""` 不复权（可传 qfq）——原「不复权断层」判断仅对默认口径成立
- 网络层（对 §十四 限频纪律的实证）：WAF 按 **TLS 指纹+版本** 拦截（LibreSSL TLS1.2 带 SNI → 0 字节响应；curl TLS1.3 可通）；DNS 多节点（部分节点 Empty reply）；**30+ 次高频请求触发 IP 级临时封禁且有扩散性**（push2his → push2 全家 HTTP 000，push2ex 例外）
- py_mini_racer 本地执行 JS = 脆重依赖（二进制组件），叠加 WAF 对抗 → 再次坐实 B 不进主链

- **路径 A（qfq 自算递推）确认为唯一主链方案**：东财版与我们是同一模型家族，无权威性优势，且有 90 日深度限制、mini_racer 依赖、WAF 对抗三重劣势
